# Hughes Farms

A digital farm management project designed to help bring everyday farm information into one place.

The project is intended for mixed farming operations and supports clearer oversight of routine activities, livestock, crops, and farm records.

## Project background

Hughes Farms reflects the practical needs of farm work: information should be easy to find and useful in the field as well as during planning.
