Deployment

The app is configured to deploy to Vercel (see vercel.json in the repo root).

The repo is no longer configured for Netlify (netlify.toml was removed in the Vercel migration). To re-enable, restore the netlify.toml from git history and follow Netlify's Next.js runtime docs.
