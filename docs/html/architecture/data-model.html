Architecture

Data model

The Hughes Farms schema lives in two places that must stay in sync…

Every server-side row carries a farm_id matching the user's tenant. The JWT exposes farm_id; API handlers must filter by it. The single exception is is_superadmin === true, which bypasses the farm_id filter and can aggregate across tenants (used by the /admin/users screen and the cross-farm dashboard view).
