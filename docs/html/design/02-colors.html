02 · Color tokens

The palette is split into three layers, all defined as CSS variables in app/globals.css and exposed to Tailwind via the @theme inline block (so JSX keeps using utilities like bg-primary / text-foreground / border-border).

@theme inline is Tailwind 4's "expose this CSS variable as a utility" syntax — --color-X becomes bg-X, text-X, border-X, ring-X, etc. The inline keyword tells Tailwind to keep the values as var(…) references instead of inlining the literal, so dark-mode switches automatically when the .dark class lands on .
