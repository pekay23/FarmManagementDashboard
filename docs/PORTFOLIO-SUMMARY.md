# Hughes Farms — Project Summary

Hughes Farms is a farm management project for organising everyday records and activities in one place. Its application includes areas for crops, livestock, inventory, staff, tasks, sales, and reports.

The project combines browser-based records with server-backed services. Some workflows use local storage and synchronization; their offline behavior should be assessed individually. Earlier versions of this summary described an installable service-worker application and an automatic lint patch that are not established by the current package configuration.

For project context, see the [system overview](./architecture/system-overview.md).
