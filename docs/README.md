# Hughes Farms - Project Background

This folder contains supporting material for the Hughes Farms digital project.

The project explores ways to make farm information and everyday record keeping easier to manage. Documents here provide additional context for contributors and may include working plans.

Start with the project README at the repository root for a brief overview.
